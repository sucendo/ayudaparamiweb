Cómo escribir una meta description útil

Una buena descripción no sustituye al contenido, pero ayuda a explicar de forma clara qué encontrará el usuario al entrar en la página.

Actualizado en septiembre de 2019 ·

Resume la intención de la página

La descripción debería condensar el propósito real de la URL. Si una página es una guía, explica qué aprenderá el visitante; si es una herramienta, indica qué puede hacer con ella.

No repitas la misma en todas las páginas

Las descripciones genéricas pierden utilidad cuando se copian de una URL a otra. Es preferible escribir una frase específica para cada contenido importante.

Consejo: escribe primero una frase natural y después recórtala. Es más fácil conservar el sentido así que intentar redactar directamente pensando en un límite exacto.

Incluye las palabras importantes de forma natural

Utiliza términos que permitan reconocer rápidamente el tema, pero evita convertir la descripción en una sucesión de palabras clave. Debe seguir siendo una frase comprensible.

No prometas algo que la página no ofrece

Una descripción puede atraer el clic, pero si genera una expectativa falsa perjudica la experiencia. El texto debe representar con fidelidad el contenido al que conduce.
