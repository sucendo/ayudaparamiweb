Cómo optimizar imágenes para una página web

Reducir el peso de las imágenes es una de las mejoras más sencillas para conseguir páginas que carguen con mayor rapidez.

Actualizado en septiembre de 2019 ·

Empieza por el tamaño real

No tiene sentido subir una fotografía de varios miles de píxeles si se va a mostrar dentro de un bloque de 800 píxeles. Redimensionar antes de publicar evita transferir datos que el visitante nunca llega a aprovechar.

Escoge el formato adecuado

JPEG suele ser apropiado para fotografías, PNG para gráficos que necesitan transparencia y SVG para iconos o ilustraciones vectoriales. Elegir el formato correcto puede reducir mucho el peso sin cambiar el aspecto de la página.

Consejo: guarda siempre una copia del original y genera una versión específica para la web.

Comprime sin obsesionarte con el 100%

Una compresión moderada acostumbra a ser suficiente. El objetivo no es conseguir el archivo más pequeño posible, sino encontrar un equilibrio entre peso y calidad que no resulte visible para la mayoría de usuarios.

Incluye dimensiones y texto alternativo

Definir el ancho y el alto ayuda a reservar el espacio antes de que cargue la imagen. El atributo alt debe describir la imagen cuando aporta información y puede dejarse vacío cuando es puramente decorativa.
