Cómo hacer una página web más rápida

Antes de buscar soluciones complejas conviene revisar las decisiones básicas: imágenes, archivos CSS y JavaScript, recursos externos y contenido que se descarga.

Actualizado en septiembre de 2019 ·

Reduce lo que realmente se descarga

La mejora más directa consiste en enviar menos datos. Imágenes sobredimensionadas, librerías que apenas se utilizan y archivos duplicados pueden aumentar el tiempo de carga sin aportar valor visible.

Agrupa y ordena tus recursos

Mantener CSS y JavaScript organizados facilita detectar código que ya no se necesita. Una página sencilla no debería depender de decenas de archivos si puede resolver la misma tarea con una estructura más pequeña.

Consejo: mide antes y después de cada cambio. Sin una referencia inicial es difícil saber qué optimización ha producido una mejora real.

Evita bloquear la carga sin necesidad

Los scripts que no son imprescindibles para mostrar el contenido principal pueden cargarse de forma que no retrasen la primera visualización. La prioridad debería ser que el usuario pueda leer y utilizar la página cuanto antes.

Optimiza imágenes y fuentes

Estos recursos pueden representar una parte importante del peso total. Sirve tamaños adecuados, limita variantes tipográficas y evita descargar archivos que no se usan en la vista actual.
